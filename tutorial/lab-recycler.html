Adapter + ViewHolder — ciclo

public class ContactAdapter extends RecyclerView.Adapter<ContactAdapter.VH> {
  List<Contact> list; OnClick listener;
  public VH onCreateViewHolder(ViewGroup parent, int viewType){
    View v = LayoutInflater.from(parent.getContext()).inflate(R.layout.item_contact, parent, false);
    return new VH(v); // ViewHolder cachea findViewById
  }
  public void onBindViewHolder(VH h, int pos){
    Contact c = list.get(pos);
    h.tvName.setText(c.name); h.tvEmail.setText(c.email); h.tvPhone.setText(c.phone);
    h.imgPhoto.setImageResource(c.photoRes);
    h.itemView.setOnClickListener(v -> listener.onClick(c));
  }
  static class VH extends RecyclerView.ViewHolder {
    TextView tvName,tvEmail,tvPhone; ImageView imgPhoto;
    VH(View v){ super(v); tvName=v.findViewById(R.id.tvName); /*...*/ }
  }
}

ScrollView vs RecyclerView

Aspecto ScrollView RecyclerView
Items 10 fijos en memoria ~7 visibles recicladas
Performance Lag con 100+ Fluido con 1000+
API addView loop Adapter + ViewHolder
Mutación addView manual notifyItemInserted

Cómo se desarrolló

  1. Crea Contact.java (name, email, phone, photoRes) y item_contact.xml con Card 48dp + 3 TextViews.
  2. Crea ContactAdapter.java con onCreateViewHolder inflate + onBindViewHolder bind + VH cache.
  3. Crea activity_contact_recycler.xml con header card + RecyclerView weight=1 + TextView empty gone.
  4. En ContactRecyclerActivity set LayoutManager, fill 8 contactos, setAdapter, listener Toast + Log, botón Add con notifyItemInserted.
  5. Añade dependencia recyclerview:1.3.2 + strings acrecy_* en 4 locales + entrada Manifest + card en Home.
