Estrategia de Validación en 3 Capas

Arquitectura desacoplada en 3 capas: Capa 1: Lógica Pura (ValidationUtils sin dependencias Android para tests unitarios), Capa 2: Orquestación UI (evaluación atómica al pulsar botón) y Capa 3: Reactividad (TextWatcher para limpieza visual de errores).

Capa 1: ValidationUtils.java (Lógica Desacoplada)

100% Testeable

No requiere Context ni referencias al hilo de interfaz gráfica, permitiendo ejecución instantánea en tests JUnit locales. 

package com.example.sandbox.utils;

import android.util.Patterns;
import java.util.regex.Pattern;

public class ValidationUtils {

    private static final Pattern PHONE = Pattern.compile("^\\+?[0-9 ]{9,15}$");
    private static final Pattern POSTAL = Pattern.compile("^\\d{5}$");
    private static final Pattern PIN = Pattern.compile("^\\d{4,6}$");

    public static boolean isRequired(String text) {
        return text != null && !text.trim().isEmpty();
    }

    public static boolean isEmail(String text) {
        return isRequired(text) && Patterns.EMAIL_ADDRESS.matcher(text.trim()).matches();
    }

    public static boolean isPassword(String text) {
        return isRequired(text) && text.length() >= 6;
    }

    public static boolean isNumericPassword(String text) {
        return isRequired(text) && PIN.matcher(text.trim()).matches();
    }

    public static boolean isPhone(String text) {
        return isRequired(text) && PHONE.matcher(text.trim()).matches();
    }

    public static boolean isPostalCode(String text) {
        return isRequired(text) && POSTAL.matcher(text.trim()).matches();
    }

    public static boolean isNotFuture(long epochMillis) {
        return epochMillis <= System.currentTimeMillis();
    }
}

Capa 2: Orquestación al Pulsar Botón

Atomic Check

Evalúa secuencialmente los campos. Detiene el flujo si existen fallos y notifica al usuario. 

boolean isValid = true;

if (!ValidationUtils.isRequired(email)) {
    tilEmail.setError(getString(R.string.common_err_required));
    isValid = false;
} else if (!ValidationUtils.isEmail(email)) {
    tilEmail.setError(getString(R.string.common_err_email));
    isValid = false;
} else {
    tilEmail.setError(null);
}

if (!isValid) {
    Toast.makeText(this, getString(R.string.common_msg_correct_errors), Toast.LENGTH_SHORT).show();
    return;
}

Capa 3: TextWatcher Reactivo

Live Cleanup

Limpia el mensaje rojo en cuanto el usuario introduce datos que cumplen la regla. 

etEmail.addTextChangedListener(new SimpleTextWatcher() {
    @Override
    public void afterTextChanged(Editable s) {
        if (ValidationUtils.isEmail(s.toString())) {
            tilEmail.setError(null);
        }
    }
});
