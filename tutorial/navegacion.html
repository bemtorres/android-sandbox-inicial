Patrones Core Intent / Bundle / Prefs / SharedPreferences

Navegación & Paso de Datos entre Vistas

Guía técnica exhaustiva sobre cómo estructurar la transición entre pantallas en Android mediante Intent Explícito, transferencia atómica de parámetros mediante putExtra / Bundle y persistencia de sesión con SharedPreferences.

1. Intent Explícito

Transición directa donde el origen conoce exactamente la clase destino (Destino.class). Registrada en el Manifest.

2. Extras & Bundle

Transferencia en memoria de tipos primitivos, Strings y objetos Parcelable mediante el contenedor clave-valor.

3. SharedPreferences

Persistencia en disco para datos que deben sobrevivir al ciclo de vida de la Activity (como sesión o último email usado).

1. Disparo de Navegación & Gestión de Back Stack

Cada llamada a startActivity() crea una nueva instancia y la apila en el Back Stack. El botón atrás del sistema desapila (pop) automáticamente. 

// Navegación básica hacia otra Activity
Intent intent = new Intent(MainActivity.this, RegisterActivity.class);
startActivity(intent);

// Cerrar la Activity actual sin apilarla
finish();

// Limpiar todo el stack al cerrar sesión (Logout)
Intent logoutIntent = new Intent(this, MainActivity.class);
logoutIntent.addFlags(Intent.FLAG_ACTIVITY_NEW_TASK | Intent.FLAG_ACTIVITY_CLEAR_TASK);
startActivity(logoutIntent);
// Navegación básica hacia otra Activity
val intent = Intent(this, RegisterActivity::class.java)
startActivity(intent)

// Cerrar la Activity actual sin apilarla
finish()

// Limpiar todo el stack al cerrar sesión (Logout)
val logoutIntent = Intent(this, MainActivity::class.java).apply {
    addFlags(Intent.FLAG_ACTIVITY_NEW_TASK or Intent.FLAG_ACTIVITY_CLEAR_TASK)
}
startActivity(logoutIntent)

2. Paso y Recuperación de Extras

Envío y Recepción en Java

// --- ENVIAR DATOS (MainActivity.java) ---
Intent intent = new Intent(this, IntroActivity.class);
intent.putExtra("user_name", "Benjamín");
intent.putExtra("user_email", "benjamin@ejemplo.com");
intent.putExtra("user_level", 2);
startActivity(intent);

// --- RECUPERAR DATOS (IntroActivity.java) ---
String name  = getIntent().getStringExtra("user_name");
String email = getIntent().getStringExtra("user_email");
int level    = getIntent().getIntExtra("user_level", 1); // 1 es el valor por defecto

// Fallback preventivo si el intent vino vacío
if (email == null || email.isEmpty()) {
    email = Prefs.getUser(this);
}

Envío y Recepción en Kotlin

// --- ENVIAR DATOS (MainActivity.kt) ---
val intent = Intent(this, IntroActivity::class.java).apply {
    putExtra("user_name", "Benjamín")
    putExtra("user_email", "benjamin@ejemplo.com")
    putExtra("user_level", 2)
}
startActivity(intent)

// --- RECUPERAR DATOS (IntroActivity.kt) ---
val name  = intent.getStringExtra("user_name").orEmpty()
val email = intent.getStringExtra("user_email") ?: Prefs.getUser(this)
val level = intent.getIntExtra("user_level", 1)

3. Persistencia Ligera: Prefs

public class Prefs {
    private static final String PREF_FILE = "sandbox_prefs";
    private static final String KEY_USER  = "user_email";

    public static void saveUser(Context context, String email) {
        context.getSharedPreferences(PREF_FILE, Context.MODE_PRIVATE)
               .edit()
               .putString(KEY_USER, email)
               .apply(); // apply() es asíncrono y no bloquea el hilo principal UI
    }

    public static String getUser(Context context) {
        return context.getSharedPreferences(PREF_FILE, Context.MODE_PRIVATE)
                      .getString(KEY_USER, "");
    }
}
object Prefs {
    private const val PREF_FILE = "sandbox_prefs"
    private const val KEY_USER = "user_email"

    fun saveUser(context: Context, email: String) {
        context.getSharedPreferences(PREF_FILE, Context.MODE_PRIVATE)
            .edit()
            .putString(KEY_USER, email)
            .apply() // apply() es asíncrono, no bloquea UI
    }

    fun getUser(context: Context): String {
        return context.getSharedPreferences(PREF_FILE, Context.MODE_PRIVATE)
            .getString(KEY_USER, "") ?: ""
    }
}

// Uso más idiomático con extensión:
val String.isValidEmail: Boolean get() = ValidationUtils.isEmail(this)
Prefs.saveUser(this, email)
val saved = Prefs.getUser(this)

✕ Errores Frecuentes

  • Olvidar declarar la Activity en AndroidManifest.xml.
  • Typo en las claves de los extras ("emial" vs "email").
  • Pasar objetos pesados (>1MB) por Intent causando TransactionTooLargeException.
  • No proporcionar valor por defecto al leer primitivos con getIntExtra().

✓ Buenas Prácticas

  • Declarar android:exported="false" en Activities internas.
  • Usar constantes para las claves de los extras (EXTRA_EMAIL).
  • Aplicar siempre trim() a los textos antes de empaquetarlos en el Intent.
  • Configurar windowSoftInputMode="adjustResize" para no tapar los botones de acción.
