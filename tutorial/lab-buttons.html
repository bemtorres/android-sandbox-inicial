Lab 3 — Button · ImageButton · Chip

Cómo funciona un click, cómo evitar doble click (debounce), por qué ImageButton necesita contentDescription y cómo ChipGroup maneja selección única.

Button + debounce + enabled toggle

long lastClick = 0;
btnNormal.setOnClickListener(v -> {
  long now = System.currentTimeMillis();
  if(now - lastClick < 500){ Log.w(TAG,"debounce"); return; }
  lastClick = now;
  tvStatus.setText(getString(R.string.acbutt_status_button, String.valueOf(now)));
  Toast.makeText(this, getString(R.string.acbutt_toast_button), SHORT).show();
});
btnToggle.setOnClickListener(v -> {
  boolean enabled = btnNormal.isEnabled();
  btnNormal.setEnabled(!enabled); // estado lógico vs visual
  tvStatus.setText(getString(enabled ? R.string.acbutt_status_disabled : R.string.acbutt_status_enabled));
});

500ms evita doble envío si usuario toca rápido. setEnabled deshabilita ripple y alpha automáticamente.

ImageButton

<ImageButton
  android:id="@+id/imgBtn"
  android:contentDescription="@string/acbutt_image_desc" // obligatorio a11y
  android:src="@mipmap/ic_launcher_round"
  android:background="?attr/selectableItemBackgroundBorderless"/>

Es un ImageView con clickable. contentDescription lo lee TalkBack. selectableItemBackgroundBorderless da ripple circular.
