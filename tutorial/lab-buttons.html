MaterialButton, ImageButton y ChipGroup

Explora los tres controles de acción esenciales: control de pulsaciones rápidas (Debounce), botones de imagen con accesibilidad (contentDescription para TalkBack) y selección única con ChipGroup.

1. Capturas del Emulador

1

MaterialButton · Debounce & Toggle de Estado

Control de Clics

El debounce de 500 ms previene envíos duplicados en llamadas a backend. El botón toggle alterna el estado setEnabled(boolean), modificando automáticamente el ripple y el alpha visual. 

<com.google.android.material.button.MaterialButton
    android:id="@+id/btnNormal"
    android:layout_width="match_parent"
    android:layout_height="wrap_content"
    android:text="@string/acbutt_btn_normal" />

<com.google.android.material.button.MaterialButton
    android:id="@+id/btnToggle"
    style="@style/Widget.Material3.Button.OutlinedButton"
    android:layout_width="match_parent"
    android:layout_height="wrap_content"
    android:text="@string/acbutt_btn_toggle" />
long lastClick = 0;

btnNormal.setOnClickListener(v -> {
    long now = System.currentTimeMillis();
    if (now - lastClick < 500) {
        Log.w(TAG, "Debounce: click ignorado para evitar doble envío");
        return;
    }
    lastClick = now;
    tvStatus.setText(getString(R.string.acbutt_status_button, "1"));
    Toast.makeText(this, getString(R.string.acbutt_toast_button), Toast.LENGTH_SHORT).show();
});

btnToggle.setOnClickListener(v -> {
    boolean isCurrentlyEnabled = btnNormal.isEnabled();
    btnNormal.setEnabled(!isCurrentlyEnabled);
    tvStatus.setText(getString(!isCurrentlyEnabled ? R.string.acbutt_status_enabled : R.string.acbutt_status_disabled));
});

ImageButton · Ripple Circular & Accesibilidad TalkBack

A11y + Ripple

Un ImageButton sin contentDescription genera advertencias de accesibilidad severas en Android Lint. El fondo ?attr/selectableItemBackgroundBorderless proporciona el efecto de onda circular (ripple) característico de Material 3. 

<ImageButton
    android:id="@+id/imgBtn"
    android:layout_width="48dp"
    android:layout_height="48dp"
    android:contentDescription="@string/acbutt_image_desc"
    android:src="@mipmap/ic_launcher_round"
    android:background="?attr/selectableItemBackgroundBorderless" />

ChipGroup · Filtro Exclusivo (singleSelection="true")

Filtros de Datos

app:singleSelection="true" garantiza que solo un chip permanezca activo a la vez (comportamiento idéntico a un RadioGroup horizontal con estética moderna). 

<com.google.android.material.chip.ChipGroup
    android:id="@+id/chipGroup"
    android:layout_width="match_parent"
    android:layout_height="wrap_content"
    app:singleSelection="true">

    <com.google.android.material.chip.Chip
        android:id="@+id/chip1"
        style="@style/Widget.Material3.Chip.Filter"
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:text="@string/acbutt_chip_android" />

    <com.google.android.material.chip.Chip
        android:id="@+id/chip2"
        style="@style/Widget.Material3.Chip.Filter"
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:text="@string/acbutt_chip_java" />

    <com.google.android.material.chip.Chip
        android:id="@+id/chip3"
        style="@style/Widget.Material3.Chip.Filter"
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:text="@string/acbutt_chip_kotlin" />
</com.google.android.material.chip.ChipGroup>
chipGroup.setOnCheckedStateChangeListener((group, checkedIds) -> {
    if (checkedIds.isEmpty()) {
        tvStatus.setText(getString(R.string.acbutt_status_chip, getString(R.string.common_none)));
        return;
    }
    int selectedId = checkedIds.get(0);
    String label = "";
    if (selectedId == R.id.chip1) label = getString(R.string.acbutt_chip_android);
    else if (selectedId == R.id.chip2) label = getString(R.string.acbutt_chip_java);
    else if (selectedId == R.id.chip3) label = getString(R.string.acbutt_chip_kotlin);

    tvStatus.setText(getString(R.string.acbutt_status_chip, label));
});
