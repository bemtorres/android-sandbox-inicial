MaterialButton · Debounce & Toggle de Estado

Control de Clics

El debounce de 500 ms evita envíos dobles o llamadas redundantes a APIs cuando el usuario pulsa repetidamente. El botón toggle alterna el estado setEnabled(boolean), modificando automáticamente el ripple y el alpha visual.

XML Layout · activity_buttons.xml XML 
<com.google.android.material.button.MaterialButton
    android:id="@+id/btnNormal"
    android:layout_width="match_parent"
    android:layout_height="wrap_content"
    android:text="@string/acbutt_btn_normal" />

<com.google.android.material.button.MaterialButton
    android:id="@+id/btnToggle"
    style="@style/Widget.Material3.Button.OutlinedButton"
    android:layout_width="match_parent"
    android:layout_height="wrap_content"
    android:text="@string/acbutt_btn_toggle" />
Java Controller · ButtonsActivity.java (Listeners y Debounce) Java 
private long lastClickTime = 0;

private void setupButtonListeners() {
    MaterialButton btnNormal = findViewById(R.id.btnNormal);
    MaterialButton btnToggle = findViewById(R.id.btnToggle);
    TextView tvStatus = findViewById(R.id.tvStatus);

    btnNormal.setOnClickListener(v -> {
        long currentTime = System.currentTimeMillis();
        // Umbral de debounce: 500 milisegundos
        if (currentTime - lastClickTime < 500) {
            Log.w("SANDBOX_BUTTONS", "Clic ignorado por debounce (<500ms)");
            return;
        }
        lastClickTime = currentTime;

        tvStatus.setText(getString(R.string.acbutt_status_button, String.valueOf(currentTime)));
        Toast.makeText(this, getString(R.string.acbutt_toast_button), Toast.LENGTH_SHORT).show();
    });

    btnToggle.setOnClickListener(v -> {
        boolean isCurrentlyEnabled = btnNormal.isEnabled();
        btnNormal.setEnabled(!isCurrentlyEnabled); // Alterna estado lógico y visual
        tvStatus.setText(getString(isCurrentlyEnabled ? R.string.acbutt_status_disabled : R.string.acbutt_status_enabled));
    });
}

ImageButton · Ripple y Accesibilidad TalkBack

Icon Buttons

Un ImageButton es un ImageView clickeable. Requiere obligatoriamente android:contentDescription para que los lectores de pantalla (TalkBack) verbalicen su acción a usuarios con discapacidad visual.

XML Layout · activity_buttons.xml (ImageButton) XML 
<ImageButton
    android:id="@+id/imgBtn"
    android:layout_width="56dp"
    android:layout_height="56dp"
    android:contentDescription="@string/acbutt_image_desc"
    android:src="@mipmap/ic_launcher_round"
    android:background="?attr/selectableItemBackgroundBorderless" />
Java Controller · ButtonsActivity.java (ImageButton Listener) Java 
ImageButton imgBtn = findViewById(R.id.imgBtn);
imgBtn.setOnClickListener(v -> {
    Log.i("SANDBOX_BUTTONS", "ImageButton pulsado");
    tvStatus.setText(getString(R.string.acbutt_status_image_clicked));
    Toast.makeText(this, getString(R.string.acbutt_toast_image), Toast.LENGTH_SHORT).show();
});

ChipGroup · Filtro Exclusivo (Single Selection)

Material 3 Chips

Con app:singleSelection="true", el ChipGroup se comporta como un grupo radial estilizado en pastillas (chips). El listener setOnCheckedStateChangeListener entrega la lista de IDs seleccionados de forma reactiva.

XML Layout · activity_buttons.xml (ChipGroup con 4 chips) XML 
<com.google.android.material.chip.ChipGroup
    android:id="@+id/chipGroup"
    android:layout_width="match_parent"
    android:layout_height="wrap_content"
    app:singleSelection="true">

    <com.google.android.material.chip.Chip
        android:id="@+id/chip1"
        style="@style/Widget.Material3.Chip.Filter"
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:text="@string/acbutt_chip_android" />

    <com.google.android.material.chip.Chip
        android:id="@+id/chip2"
        style="@style/Widget.Material3.Chip.Filter"
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:text="@string/acbutt_chip_java" />

    <com.google.android.material.chip.Chip
        android:id="@+id/chip3"
        style="@style/Widget.Material3.Chip.Filter"
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:text="@string/acbutt_chip_kotlin" />

    <com.google.android.material.chip.Chip
        android:id="@+id/chip4"
        style="@style/Widget.Material3.Chip.Filter"
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:text="@string/acbutt_chip_compose" />
</com.google.android.material.chip.ChipGroup>
Java Controller · ButtonsActivity.java (ChipGroup Listener) Java 
ChipGroup chipGroup = findViewById(R.id.chipGroup);
chipGroup.setOnCheckedStateChangeListener((group, checkedIds) -> {
    if (checkedIds.isEmpty()) {
        tvStatus.setText(getString(R.string.acbutt_status_chip_none));
        Log.d("SANDBOX_BUTTONS", "ChipGroup deseleccionado");
        return;
    }

    int selectedId = checkedIds.get(0);
    String label = "";
    if (selectedId == R.id.chip1) label = getString(R.string.acbutt_chip_android);
    else if (selectedId == R.id.chip2) label = getString(R.string.acbutt_chip_java);
    else if (selectedId == R.id.chip3) label = getString(R.string.acbutt_chip_kotlin);
    else if (selectedId == R.id.chip4) label = getString(R.string.acbutt_chip_compose);

    tvStatus.setText(getString(R.string.acbutt_status_chip, label));
    Log.i("SANDBOX_BUTTONS", "Chip seleccionado: " + label);
});
