Lab 7 — Dialog · Toast · Logger

Tres canales: Toast efímero no bloqueante, AlertDialog modal bloqueante y Logcat persistente.

Toast — dos duraciones

Toast.makeText(this, getString(R.string.acdito_toast_short), LENGTH_SHORT).show(); // ~2s
Toast.makeText(this, getString(R.string.acdito_toast_long), LENGTH_LONG).show();  // ~3.5s

No necesita permiso. Se encola: si lanzas 2 seguidos, el segundo espera. makeText requiere Context activity para theming.

AlertDialog.Builder — confirmación

new AlertDialog.Builder(this)
  .setTitle(getString(R.string.acdito_dialog_title)) // "Confirmación"
  .setMessage(getString(R.string.acdito_dialog_msg))
  .setPositiveButton(getString(R.string.acdito_dialog_yes), (d,w)-> {
    appendLog(getString(R.string.acdito_log_yes));
    Toast.makeText(this, getString(R.string.acdito_toast_yes), SHORT).show();
  })
  .setNegativeButton(getString(R.string.acdito_dialog_no), (d,w)-> appendLog(getString(acdito_log_no)))
  .setNeutralButton(getString(R.string.acdito_dialog_cancel), null)
  .show();

Tres botones = positive/negative/neutral. Pasar null cierra sin acción.

AlertDialog con lista

final String[] items = {"Java","Kotlin","Python"};
new AlertDialog.Builder(this)
  .setTitle(getString(R.string.acdito_dialog_list_title))
  .setItems(items, (d,which)->{
    String sel = items[which];
    appendLog(getString(R.string.acdito_log_list, sel)); // "Lista: Java"
    Toast.makeText(this, getString(R.string.acdito_toast_chosen, sel), SHORT).show();
  }).show();

setItems hace lista simple sin adapter. Para lista con check usa setSingleChoiceItems.

LoggerUtils — 5 niveles

LoggerUtils.v(TAG,"VERBOSE"); Log.v
LoggerUtils.d(TAG,"DEBUG");   Log.d // flujo
LoggerUtils.i(TAG,"INFO");    Log.i // éxito
LoggerUtils.w(TAG,"WARN");    Log.w // recuperable
LoggerUtils.e(TAG,"ERROR");   Log.e // validación fallida
LoggerUtils.demo(TAG); // dispara v/d/i/w/e a la vez
VDIWE

tvLog.append(getString(acdito_log_append, msg)) acumula en UI + Logcat con tag SANDBOX_DIALOG.

Cómo se desarrolló

  1. Layout ScrollView + Card acdito_info_desc + TextView tvLog con acdito_log_default + 5 MaterialButtons (acdit_btn_short/long/alert/list/logger).
  2. onCreate: findViewById para 5 botones + tvLog.
  3. Cada click: Toast o AlertDialog.Builder + appendLog + LoggerUtils.
  4. appendLog(String msg){ tvLog.append(getString(acdito_log_append, msg)); } → acumula con bullet.
