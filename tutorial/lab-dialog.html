Lab 7 · Dialog / Toast / Logger

Implementación integral de los 3 canales de comunicación con el usuario y desarrollo: Toast (retroalimentación instantánea no bloqueante), AlertDialog (modal bloqueante de confirmación o selección) y LoggerUtils (trazabilidad y diagnóstico en Logcat con consola en pantalla).

Implementación de Código

1. Toast Notifications (Short & Long)

Context + Length

Notificación liviana que desaparece automáticamente. Requiere un Context (como la Activity) para heredar el tema de la aplicación. 

// Toast de duración corta (~2.0 segundos)
Toast.makeText(this, getString(R.string.acdito_toast_short), Toast.LENGTH_SHORT).show();

// Toast de duración larga (~3.5 segundos)
Toast.makeText(this, getString(R.string.acdito_toast_long), Toast.LENGTH_LONG).show();

2. AlertDialog Modal de Confirmación

AlertDialog.Builder

Diálogo modal que captura la atención del usuario requiriendo una acción explícita mediante botones de acción. 

new AlertDialog.Builder(this)
    .setTitle(getString(R.string.acdito_dialog_title)) // "Confirmación"
    .setMessage(getString(R.string.acdito_dialog_msg))
    .setPositiveButton(getString(R.string.acdito_dialog_yes), (dialog, which) -> {
        appendLog(getString(R.string.acdito_log_yes));
        Toast.makeText(this, getString(R.string.acdito_toast_yes), Toast.LENGTH_SHORT).show();
    })
    .setNegativeButton(getString(R.string.acdito_dialog_no), (dialog, which) -> {
        appendLog(getString(R.string.acdito_log_no));
    })
    .setNeutralButton(getString(R.string.acdito_dialog_cancel), null)
    .show();

3. AlertDialog con Lista de Opciones

setItems Listener

Despliega un menú modal de opciones rápidas sin necesidad de configurar un RecyclerView personalizado. 

final String[] items = {"Java", "Kotlin", "Python", "Rust"};
new AlertDialog.Builder(this)
    .setTitle(getString(R.string.acdito_dialog_list_title))
    .setItems(items, (dialog, which) -> {
        String selected = items[which];
        appendLog(getString(R.string.acdito_log_list, selected));
        Toast.makeText(this, getString(R.string.acdito_toast_chosen, selected), Toast.LENGTH_SHORT).show();
    })
    .show();

4. LoggerUtils & Acumulador en Pantalla

V D I W E

Envía trazas de diagnóstico clasificadas por severidad a Logcat y registra la salida en el TextView de consola. 

private void appendLog(String message) {
    tvLog.append(getString(R.string.acdito_log_append, message));
    LoggerUtils.d(TAG, message);
}

// Ejemplo de llamada completa con LoggerUtils
LoggerUtils.v(TAG, "Mensaje Verbose");
LoggerUtils.d(TAG, "Flujo de ejecución Debug");
LoggerUtils.i(TAG, "Operación exitosa Info");
LoggerUtils.w(TAG, "Advertencia recuperable Warn");
LoggerUtils.e(TAG, "Error o validación fallida");
LoggerUtils.demo(TAG); // Dispara ráfaga de todos los niveles

1. Toast Notifications en Kotlin

Extension Friendly 
// Toast directo conciso
Toast.makeText(this, getString(R.string.acdito_toast_short), Toast.LENGTH_SHORT).show()
Toast.makeText(this, getString(R.string.acdito_toast_long), Toast.LENGTH_LONG).show()

// Idiomático con función de extensión (opcional):
fun Context.toast(msg: String, length: Int = Toast.LENGTH_SHORT) {
    Toast.makeText(this, msg, length).show()
}

4. ViewBinding & LoggerUtils

ActivityDialogBinding 
class DialogActivity : AppCompatActivity() {

    private lateinit var binding: ActivityDialogBinding
    private val TAG = "SANDBOX_DIALOG"

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        binding = ActivityDialogBinding.inflate(layoutInflater)
        setContentView(binding.root)

        setupListeners()
    }

    private fun appendLog(message: String) {
        binding.tvLog.append(getString(R.string.acdito_log_append, message))
        LoggerUtils.d(TAG, message)
    }
}

Flujo de Arquitectura y Configuración

1. Maquetación XML (activity_dialog.xml)

Contenedor ScrollView con tarjeta descriptiva, botones MaterialButton organizados en grupos y TextView de consola tvLog.

2. Strings i18n Centralizados

Todas las cadenas de títulos, mensajes modales y etiquetas de botones residen en res/values/strings.xml bajo el prefijo acdito_.

3. Controladores de Eventos

Lambdas independientes para confirmación positiva, cancelación negativa y selección de ítems en el diálogo modal.

4. Registro Dual (UI + Logcat)

El método auxiliar appendLog() actualiza sincronizadamente el buffer del TextView y despacha a Logcat con formato.
