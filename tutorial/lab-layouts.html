Lab 8 · Layouts & ViewGroups

Análisis comparativo de jerarquía y rendimiento entre ConstraintLayout (jerarquía plana óptima con cadenas de restricciones), LinearLayout (flujo unidireccional con pesos calculados) y TableLayout (organización tabular matricial).

Estructuras de Layout en XML

1. ConstraintLayout (Recomendado)

Alta Performance

Distribuye elementos usando 0dp y anclas relativas. Evita el doble pase de renderizado de layouts anidados. 

<androidx.constraintlayout.widget.ConstraintLayout
    android:layout_width="match_parent"
    android:layout_height="wrap_content">

    <TextView
        android:id="@+id/boxA"
        android:layout_width="0dp"
        android:layout_height="60dp"
        app:layout_constraintStart_toStartOf="parent"
        app:layout_constraintEnd_toStartOf="@id/boxB"
        app:layout_constraintTop_toTopOf="parent" />

    <TextView
        android:id="@+id/boxB"
        android:layout_width="0dp"
        android:layout_height="60dp"
        app:layout_constraintStart_toEndOf="@id/boxA"
        app:layout_constraintEnd_toStartOf="@id/boxC"
        app:layout_constraintTop_toTopOf="parent" />

    <TextView
        android:id="@+id/boxC"
        android:layout_width="0dp"
        android:layout_height="60dp"
        app:layout_constraintStart_toEndOf="@id/boxB"
        app:layout_constraintEnd_toEndOf="parent"
        app:layout_constraintTop_toTopOf="parent" />
</androidx.constraintlayout.widget.ConstraintLayout>

2. LinearLayout Vertical

layout_weight="1"

Apila elementos de arriba a abajo. Reparte el espacio vertical restante de manera uniforme con layout_height="0dp". 

<LinearLayout
    android:layout_width="match_parent"
    android:layout_height="180dp"
    android:orientation="vertical">

    <Button
        android:layout_width="match_parent"
        android:layout_height="0dp"
        android:layout_weight="1"
        android:text="Opción Superior" />

    <Button
        android:layout_width="match_parent"
        android:layout_height="0dp"
        android:layout_weight="1"
        android:text="Opción Intermedia" />

    <Button
        android:layout_width="match_parent"
        android:layout_height="0dp"
        android:layout_weight="1"
        android:text="Opción Inferior" />
</LinearLayout>

3. LinearLayout Horizontal

Fila con Space

Distribuye elementos en fila única. Permite insertar vistas de separación Space con márgenes fijos. 

<LinearLayout
    android:layout_width="match_parent"
    android:layout_height="wrap_content"
    android:orientation="horizontal"
    android:gravity="center_vertical">

    <com.google.android.material.chip.Chip
        android:layout_width="0dp"
        android:layout_height="wrap_content"
        android:layout_weight="1"
        android:text="Chip A" />

    <Space
        android:layout_width="8dp"
        android:layout_height="wrap_content" />

    <com.google.android.material.chip.Chip
        android:layout_width="0dp"
        android:layout_height="wrap_content"
        android:layout_weight="1"
        android:text="Chip B" />
</LinearLayout>

4. TableLayout Matricial

stretchColumns="1"

Organiza vistas en cuadrícula estática mediante elementos TableRow. 

<TableLayout
    android:layout_width="match_parent"
    android:layout_height="wrap_content"
    android:stretchColumns="1">

    <TableRow>
        <TextView android:text="@string/aclayo_row_header1" android:textStyle="bold" />
        <TextView android:text="@string/aclayo_row_header2" android:textStyle="bold" />
    </TableRow>

    <TableRow>
        <TextView android:text="@string/aclayo_row_item1" />
        <TextView android:text="@string/aclayo_row_item2" />
    </TableRow>
</TableLayout>

package com.example.sandbox;

import android.os.Bundle;
import android.util.Log;
import androidx.appcompat.app.AppCompatActivity;

public class LayoutsActivity extends AppCompatActivity {

    private static final String TAG = "SANDBOX_LAYOUTS";

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_layouts);

        Log.d(TAG, "Demostración de contenedores ConstraintLayout vs LinearLayout vs TableLayout iniciada");
    }
}

LayoutsActivity.kt

package com.example.sandbox

import android.os.Bundle
import android.util.Log
import androidx.appcompat.app.AppCompatActivity
import com.example.sandbox.databinding.ActivityLayoutsBinding

class LayoutsActivity : AppCompatActivity() {

    private lateinit var binding: ActivityLayoutsBinding
    private val TAG = "SANDBOX_LAYOUTS"

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        binding = ActivityLayoutsBinding.inflate(layoutInflater)
        setContentView(binding.root)

        Log.d(TAG, "Demostración de contenedores ConstraintLayout vs LinearLayout vs TableLayout iniciada")
    }
}
