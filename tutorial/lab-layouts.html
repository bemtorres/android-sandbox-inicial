Lab 8 — Layouts

Comparativa visual y técnica: ConstraintLayout solo (plano) vs Linear vertical/horizontal vs TableLayout. Mismo contenido, distinto contenedor.

1. ConstraintLayout — solo (recomendado)

<androidx.constraintlayout.widget.ConstraintLayout
  android:layout_width="match_parent"
  android:layout_height="120dp">
  <TextView android:id="@+id/boxA"
    android:layout_width="0dp"
    app:layout_constraintStart_toStartOf="parent"
    app:layout_constraintEnd_toStartOf="@id/boxB"
    app:layout_constraintTop_toTopOf="parent"/>
  <TextView android:id="@+id/boxB"
    app:layout_constraintStart_toEndOf="@id/boxA"
    app:layout_constraintEnd_toStartOf="@id/boxC"/>
  <TextView android:id="@+id/boxC"
    app:layout_constraintStart_toEndOf="@id/boxB"
    app:layout_constraintEnd_toEndOf="parent"/>
</ConstraintLayout>

0dp + constraintStart/End reparte ancho sin weight. Plano único → mejor performance (flat hierarchy).

2. LinearLayout vertical

<LinearLayout
  android:orientation="vertical"
  android:layout_height="150dp">
  <Button android:layout_height="0dp"
          android:layout_weight="1" />
  <Button android:layout_height="0dp"
          android:layout_weight="1" />
  <Button android:layout_height="0dp"
          android:layout_weight="1" />
</LinearLayout>

weight="1" reparte altura equitativa. Ideal para formularios verticales.

3. LinearLayout horizontal

<LinearLayout android:orientation="horizontal"
              android:gravity="center"
              android:padding="12dp">
  <Chip android:layout_width="0dp" android:layout_weight="1"
        android:text="Chip A"/>
  <Space android:layout_width="8dp"/>
  <Chip android:layout_weight="1" android:text="Chip B"/>
  <Chip android:layout_weight="1" android:text="Chip C"/>
</LinearLayout>

Fila con Space 8dp como separador. gravity=center centra vertical.

4. TableLayout

<TableLayout android:stretchColumns="1"
             android:background="#E3F2FD">
  <TableRow> <TextView text="@string/aclayo_row_header1"/>
             <TextView text="@string/aclayo_row_header2"/> </TableRow>
  <TableRow> <TextView text="@string/aclayo_row_item1"/> </TableRow>
</TableLayout>

stretchColumns="1" estira columna central. shrinkColumns opuesto. Útil para tablas simples (no para listas largas → Recycler).

Cómo se desarrolló

  1. Crea activity_layouts.xml con ScrollView > LinearLayout + 4 secciones, cada una: título aclayo_section_* + desc + caja de color con el layout real.
  2. Constraint: 3 TextView 0dp con constraints encadenadas.
  3. Linear vertical: 3 Button weight 1. Linear horizontal: 3 Chip weight 1 + Space.
  4. Table: 1 header row con background + 2 data rows.
  5. Activity solo hace setContentView + log.
