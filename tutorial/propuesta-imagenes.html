Dónde va cada screenshot

Todos los HTML del tutorial ya tienen placeholders con borde discontinuo. Solo guarda el PNG en tutorial/assets/images/ con el nombre exacto y aparecerá solo (el placeholder se oculta con :has(img)).

Carpeta

tutorial/assets/images/

No está en Git ignore forzoso; si lo añades, recuerda git add -f. No afecta a app/.

Formato

PNG · 1280×800 layout preview · Emulador Pixel 7 50% · <500KB. Fondo claro.

Cómo capturar

Design split → cámara del Emulator → Logcat filtrado → Windows+Shift+S o adb exec-out screencap -p.
