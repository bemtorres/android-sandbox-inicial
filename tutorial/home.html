HomeActivity — Hub

activity_home.xml · ScrollView > LinearLayout + 8 MaterialCardViews (1 intro + 7 labs). Cada card es un setOnClickListener → Intent.

public class HomeActivity extends AppCompatActivity {
  protected void onCreate(Bundle b){
    super.onCreate(b);
    setContentView(R.layout.activity_home);
    findViewById(R.id.cardInputs).setOnClickListener(v -> go(TextInputsActivity.class, "TextInputs"));
    // ... 6 cards más
  }
  private void go(Class<?> cls, String label){
    Toast.makeText(this, getString(R.string.achome_toast_opening, label), SHORT).show();
    Log.d("SANDBOX_HOME", "Navegando a "+cls.getSimpleName());
    startActivity(new Intent(this, cls));
  }
}

Por qué CardView y no Button

Card da superficie Material con elevación y ripple: app:cardElevation="2dp" android:foreground="?attr/selectableItemBackground". Más clicable que lista. Título achome_card_* + descripción achome_desc_* cuentan qué inputType/API se practica.

Card intro superior achome_arch_title/desc explica patrón Hub: cada botón hace startActivity a Activity aislada.

Responsive del Home (clase real)

Aunque es ScrollView vertical, el layout no usa widths fijas. Cards match_parent + padding 16dp se adaptan a móvil/tablet. Sin breakpoint: es lista vertical que funciona de 320dp a 840dp.

320dp (móvil pequeño)

Cards a ancho completo, títulos en 2 líneas, ripple ocupa todo.

600dp (tablet)

Mismo layout, más padding lateral. Si quisieras grid 2 cols, cambia a GridLayout con spanCount 2.

Tip

ScrollView evita adjustResize aquí porque no hay EditText.
