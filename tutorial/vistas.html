Snippet — TextWatcher vs OnCheckedChange

// EditText en vivo (no validar hasta pulsar, solo limpiar error)
etEmail.addTextChangedListener(new SimpleWatcher(){
  void afterTextChanged(Editable s){
    if(ValidationUtils.isEmail(s.toString())) tilEmail.setError(null);
  }
});

// CheckBox / Switch instantáneo
cbTerms.setOnCheckedChangeListener((buttonView, isChecked) -> {
  Log.d(TAG, "cbTerms="+isChecked); // no Toast hasta validar
});

MaterialCardView como contenedor didáctico

Todas las labs tienen card superior que explica operación interna: common_label_operation + actinp_info_desc / acdati_info_desc / acbutt_info_desc .... Atributos: app:strokeColor="@color/cardStroke" app:strokeWidth="1dp" app:cardElevation="0dp" para look bordered, no elevado. Así el estudiante ve el por qué sin abrir código.
