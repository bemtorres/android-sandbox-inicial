Build, instalación y Logcat

Cómo compilar, instalar, cambiar locale y ver los 7 tags SANDBOX_* sin perderte.

Comandos

gradlew assembleDebug          # compila debug APK
gradlew installDebug           # instala en emulador/dispositivo
gradlew assembleDebug --info   # verbose
adb logcat -s SANDBOX_LOGIN SANDBOX_REGISTER SANDBOX_HOME
adb shell setprop persist.sys.locale en-US && adb reboot # cambia a en
adb shell setprop persist.sys.locale pt-BR && adb reboot # cambia a pt

APK en app/build/outputs/apk/debug/app-debug.apk.

Responsive de este tutorial — qué se arregló

Antes (problema)

  • Sidebar hidden lg:block → inaccesible en móvil.
  • Grid lg:grid-cols-[280px_1fr] sin drawer → contenido aplastado.
  • Tablas sin overflow-x → desbordan viewport.
  • Header sin hamburger.

Ahora (solución)

  • Sidebar fixed + -translate-x-full en <1024px, toggle con JS y overlay bg-black/30.
  • Header con hamburger lg:hidden.
  • Tablas con overflow-x-auto -mx-6 px-6 min-w-[520px].
  • Padding px-4 sm:px-6 y grid grid-cols-1 lg:grid-cols-[300px_minmax(0,1fr)] con min-w-0 para truncar código.
  • Cards con grid-cols-1 md:grid-cols-2/3 colapsan limpio.

Cómo probar responsive

Abre tutorial/index.html en Chrome → DevTools → Toggle device toolbar (Ctrl+Shift+M) → prueba 360px, 768px, 1024px, 1440px. Verifica que hamburger aparece <1024px y que código hace scroll-x sin romper layout.
