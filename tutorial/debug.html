Compilación, Instalación & Logcat

Guía de comandos de compilación mediante el Gradle Wrapper, instalación en emuladores y dispositivos físicos, emulación de cambios de idioma dinámicos por ADB y filtrado de eventos en Logcat.

Comandos CLI Fundamentales

Windows PowerShell / Bash 
# 1. Compilar APK en modo Debug
./gradlew assembleDebug

# 2. Instalar directamente en el emulador o dispositivo conectado
./gradlew installDebug

# 3. Compilación con detalles de dependencias y logs de error
./gradlew assembleDebug --info --stacktrace

# 4. Monitorear Logcat filtrando por tags de Sandbox
adb logcat -s SANDBOX_LOGIN SANDBOX_REGISTER SANDBOX_HOME SANDBOX_DIALOG

# 5. Cambiar el idioma del sistema a Inglés (US) y reiniciar emulador
adb shell setprop persist.sys.locale en-US && adb reboot

# 6. Cambiar el idioma del sistema a Portugués (BR) y reiniciar
adb shell setprop persist.sys.locale pt-BR && adb reboot

Matriz de Tags Centralizados de Logcat

Tag de Logcat Clase Emisora Eventos Diagnosticados
SANDBOX_LOGIN MainActivity Validación de credenciales y despacho hacia Register
SANDBOX_REGISTER RegisterActivity 6 campos evaluados y guardado en SharedPreferences
SANDBOX_INTRO IntroActivity Extracción de parámetros de Intent y apertura de Home
SANDBOX_HOME HomeActivity Rutas de navegación hacia los 10 laboratorios
SANDBOX_INPUTS TextInputsActivity Eventos de TextWatcher y validaciones de campo
SANDBOX_DATETIME DateTimeActivity Selección de fecha/hora y validación no futuro
SANDBOX_BUTTONS ButtonsActivity Control de debounce y selección de Chips
SANDBOX_SELECTION SelectionActivity Estado de checkboxes, radios y switches
SANDBOX_FEEDBACK FeedbackActivity Simulación asíncrona con Handler y RatingBar
SANDBOX_WEBVIEW WebViewActivity Carga de URLs y navegación web hacia atrás
SANDBOX_DIALOG DialogToastActivity Disparo de alertas modales y ráfagas LoggerUtils.demo
