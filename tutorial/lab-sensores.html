Lab 12 · Sensores de Hardware (SensorManager)

Aprende a interactuar con los componentes físicos del dispositivo mediante el framework de sensores de Android (SensorManager y SensorEventListener), controlando el ciclo de vida en onResume() y onPause() para optimizar batería y evitar memory leaks.

Arquitectura del Subsistema de Sensores

Android organiza el acceso al hardware en 3 piezas fundamentales:

1. SensorManager

Servicio del sistema obtenido con getSystemService(SENSOR_SERVICE). Permite listar y registrar listeners.

2. Sensor

Representa el hardware físico individual (tipo, rango máximo, resolución, fabricante y consumo en mA).

3. SensorEventListener

Interfaz que recibe los callbacks onSensorChanged(SensorEvent) con el array de lecturas en event.values[].

Experimentación y Código Detallado: Los 10 Sensores

Cada sensor incluye su explicación teórica, experimento en vivo, interfaz XML y código en Java 11 y Kotlin.

1 Acelerómetro (Sensor.TYPE_ACCELEROMETER)

Unidad: m/s²

¿Qué hace?: Mide la aceleración aplicada al dispositivo en los tres ejes físicos ($X$: lateral, $Y$: longitudinal, $Z$: perpendicular a la pantalla). Incluye la aceleración de la gravedad (~9.81 m/s² cuando el móvil descansa sobre una mesa).

🧪 Experimento Práctico: Coloca el teléfono boca arriba sobre la mesa ($Z \approx 9.81$, $X \approx 0$, $Y \approx 0$). Ahora inclínalo a la izquierda: $X$ se vuelve positivo; sacúdelo rápidamente para disparar un detector de agitación (*shake detector*).
TYPE_ACCELEROMETER 
// Registro y lectura en Java 11
Sensor accel = sensorManager.getDefaultSensor(Sensor.TYPE_ACCELEROMETER);
sensorManager.registerListener(new SensorEventListener() {
    @Override
    public void onSensorChanged(SensorEvent event) {
        float x = event.values[0]; // Inclinación lateral
        float y = event.values[1]; // Inclinación vertical
        float z = event.values[2]; // Empuje frontal
        txtValAccel.setText(String.format("X: %.2f | Y: %.2f | Z: %.2f m/s²", x, y, z));
    }
    @Override
    public void onAccuracyChanged(Sensor sensor, int accuracy) {}
}, accel, SensorManager.SENSOR_DELAY_UI);
// Registro y lectura en Kotlin
val accel = sensorManager.getDefaultSensor(Sensor.TYPE_ACCELEROMETER)
sensorManager.registerListener(object : SensorEventListener {
    override fun onSensorChanged(event: SensorEvent) {
        val (x, y, z) = event.values
        binding.txtValAccel.text = "X: %.2f | Y: %.2f | Z: %.2f m/s²".format(x, y, z)
    }
    override fun onAccuracyChanged(sensor: Sensor?, accuracy: Int) {}
}, accel, SensorManager.SENSOR_DELAY_UI)

2 Giroscopio (Sensor.TYPE_GYROSCOPE)

Unidad: rad/s

¿Qué hace?: Mide la velocidad angular de rotación alrededor de los ejes X, Y y Z en radianes por segundo. A diferencia del acelerómetro, solo detecta velocidad de giro (si el móvil está quieto, los tres valores son 0 rad/s independientemente de su inclinación).

🧪 Experimento Práctico: Mantén el teléfono inmóvil sobre la mesa (valores = 0.00 rad/s). Ahora gíralo rápidamente como las manecillas de un reloj: el eje Z registrará un pico angular instantáneo.

        }

}

4 Sensor de Luz (Sensor.TYPE_LIGHT)

Unidad: Lux (lx)

¿Qué hace?: Mide la iluminación ambiental en Lux (1 valor flotante en values[0]). Sirve para graduar el brillo de pantalla automáticamente y activar modos oscuros en aplicaciones.

🧪 Experimento Práctico: Cubre con tu dedo la cámara frontal / notch: los Lux caerán a 0 lx. Alumbra con la linterna de otro teléfono o exponlo a la luz del sol: la barra superará los 800+ Lux.
TYPE_LIGHT 
Sensor light = sensorManager.getDefaultSensor(Sensor.TYPE_LIGHT);
sensorManager.registerListener(new SensorEventListener() {
    @Override
    public void onSensorChanged(SensorEvent event) {
        float lux = event.values[0]; // 0 lx a 10,000+ lx
        txtValLight.setText(String.format("Iluminación: %.1f Lux (lx)", lux));
        progressLight.setProgress((int) Math.min(lux, 1000));
    }
    @Override
    public void onAccuracyChanged(Sensor sensor, int accuracy) {}
}, light, SensorManager.SENSOR_DELAY_UI);
val light = sensorManager.getDefaultSensor(Sensor.TYPE_LIGHT)
sensorManager.registerListener(object : SensorEventListener {
    override fun onSensorChanged(event: SensorEvent) {
        val lux = event.values[0]
        binding.txtValLight.text = "Iluminación: %.1f Lux (lx)".format(lux)
        binding.progressLight.progress = lux.toInt().coerceAtMost(1000)
    }
    override fun onAccuracyChanged(sensor: Sensor?, accuracy: Int) {}
}, light, SensorManager.SENSOR_DELAY_UI)

5 Sensor de Proximidad (Sensor.TYPE_PROXIMITY)

Unidad: cm (o Cerca/Lejos)

¿Qué hace?: Detecta la cercanía de un objeto (como la oreja o mano) respecto a la pantalla. La mayoría de fabricantes implementan un valor binario: 0.0 cm (Cerca / Cubierto) o 5.0 cm (Lejos / Despejado).

🧪 Experimento Práctico: Acerca la palma de tu mano a 2 cm de la parte superior del móvil sin tocarla: el badge cambiará dinámicamente a "🔴 Objeto Cerca" y se tornará "🟢 Despejado" al retirar la mano.
TYPE_PROXIMITY 
Sensor prox = sensorManager.getDefaultSensor(Sensor.TYPE_PROXIMITY);
sensorManager.registerListener(new SensorEventListener() {
    @Override
    public void onSensorChanged(SensorEvent event) {
        float distance = event.values[0];
        txtValProx.setText(String.format("Distancia: %.1f cm", distance));
        if (distance < prox.getMaximumRange()) {
            badgeProximity.setText("🔴 Objeto Cerca");
        } else {
            badgeProximity.setText("🟢 Despejado / Lejos");
        }
    }
    @Override
    public void onAccuracyChanged(Sensor sensor, int accuracy) {}
}, prox, SensorManager.SENSOR_DELAY_UI);
val prox = sensorManager.getDefaultSensor(Sensor.TYPE_PROXIMITY)
prox?.let { sensor ->
    sensorManager.registerListener(object : SensorEventListener {
        override fun onSensorChanged(event: SensorEvent) {
            val dist = event.values[0]
            binding.txtValProx.text = "Distancia: %.1f cm".format(dist)
            binding.badgeProximity.text = if (dist < sensor.maximumRange) "🔴 Cerca" else "🟢 Lejos"
        }
        override fun onAccuracyChanged(sensor: Sensor?, accuracy: Int) {}
    }, sensor, SensorManager.SENSOR_DELAY_UI)
}

10 Vector de Rotación (Sensor.TYPE_ROTATION_VECTOR)

Cuaterniones 3D

¿Qué hace?: Combina acelerómetro, giroscopio y magnetómetro para calcular la orientación espacial 3D absoluta del dispositivo en forma de cuaternión ($[x \cdot \sin(\theta/2), y \cdot \sin(\theta/2), z \cdot \sin(\theta/2), \cos(\theta/2)]$). Imprescindible para Realidad Aumentada (ARCore) y tracking 3D sin efecto *gimbal lock*.

TYPE_ROTATION_VECTOR 
Sensor rot = sensorManager.getDefaultSensor(Sensor.TYPE_ROTATION_VECTOR);
sensorManager.registerListener(new SensorEventListener() {
    @Override
    public void onSensorChanged(SensorEvent event) {
        float qx = event.values[0];
        float qy = event.values[1];
        float qz = event.values[2];
        float cos = event.values.length > 3 ? event.values[3] : 0f;
        txtValRotation.setText(String.format("X: %.2f | Y: %.2f | Z: %.2f | Cos: %.2f", qx, qy, qz, cos));
    }
    @Override
    public void onAccuracyChanged(Sensor sensor, int accuracy) {}
}, rot, SensorManager.SENSOR_DELAY_UI);
val rot = sensorManager.getDefaultSensor(Sensor.TYPE_ROTATION_VECTOR)
sensorManager.registerListener(object : SensorEventListener {
    override fun onSensorChanged(event: SensorEvent) {
        val qx = event.values[0]
        val qy = event.values[1]
        val qz = event.values[2]
        val cos = if (event.values.size > 3) event.values[3] else 0f
        binding.txtValRotation.text = "X: %.2f | Y: %.2f | Z: %.2f | Cos: %.2f".format(qx, qy, qz, cos)
    }
    override fun onAccuracyChanged(sensor: Sensor?, accuracy: Int) {}
}, rot, SensorManager.SENSOR_DELAY_UI)
