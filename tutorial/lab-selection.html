Lab 4 — CheckBox · RadioButton · Switch

Tres modelos de selección: múltiple, exclusivo y toggle. Validación combinada con fail rápido.

Vistas y APIs

<CheckBox android:text="@string/acsele_cb_terms"/> // isChecked()
<CheckBox android:text="@string/acsele_cb_newsletter"/>

<RadioGroup android:id="@+id/rgOptions">
  <RadioButton text="@string/acsele_rb_free"/>
  <RadioButton text="@string/acsele_rb_pro"/>
  <RadioButton text="@string/acsele_rb_ent"/>
</RadioGroup> // getCheckedRadioButtonId() == -1 si ninguno

<SwitchMaterial text="@string/acsele_sw_notif"/>
<SwitchMaterial text="@string/acsele_sw_dark"/>

Listeners

cbTerms.setOnCheckedChangeListener((b,c)-> Log.d(TAG,"cbTerms="+c));
rg.setOnCheckedChangeListener((g,id)-> Log.d(TAG,"radio="+id));
swNotif.setOnCheckedChangeListener((b,c)-> Log.d(TAG,"switch="+c));

Cada cambio logea. No valida hasta pulsar botón.

Validación combinada — orden importa

boolean terms = cbTerms.isChecked();
int radio = rg.getCheckedRadioButtonId(); // -1 si vacío
if(!terms){
  Toast.makeText(this, getString(R.string.acsele_toast_terms), SHORT).show();
  tvResult.setText(getString(R.string.acsele_result_terms_fail)); // ❌ acepta términos
  return; // fail rápido
}
if(radio==-1){
  Toast.makeText(this, getString(R.string.acsele_toast_plan), SHORT).show();
  tvResult.setText(getString(R.string.acsele_result_plan_fail));
  return;
}
String plan = radio==R.id.rbFree? getString(acsele_rb_free) : ...;
String res = getString(R.string.acsele_result_detail, plan, newsletter?"Sí":"No", notif?"on":"off", dark?"on":"off");
tvResult.setText(getString(R.string.acsele_result_ok, res));

Terminal: TextView id=tvSelectionResult con acsele_result_default → terms_fail → plan_fail → result_ok.

Cómo se desarrolló

  1. Layout ScrollView + Card acsele_info_desc + 2 CheckBox + RadioGroup 3 opciones + 2 SwitchMaterial + TextView result + Button validate.
  2. En onCreate: findViewById 6 vistas + 5 listeners que solo logean.
  3. Validar recorre 3 tipos: boolean terms (obligatorio), int radio (exclusivo), boolean notif/dark (opcional pero se reporta).
