Lab 9 · Lista Simple con ScrollView

Construcción de listas dinámicas mediante ScrollView + LinearLayout e inflado programático con LayoutInflater.inflate(). Ideal para colecciones pequeñas y estáticas (< 20 elementos) donde no se justifica la complejidad de un RecyclerView con Adapter.

Implementación de Inflado

1. Inflado Programático en Bucle (Java)

LinearLayout container = findViewById(R.id.container);
LayoutInflater inflater = LayoutInflater.from(this);

for (String[] row : contactData) {
    View item = inflater.inflate(R.layout.item_contact, container, false);
    
    TextView tvName = item.findViewById(R.id.tvName);
    TextView tvEmail = item.findViewById(R.id.tvEmail);
    TextView tvPhone = item.findViewById(R.id.tvPhone);

    tvName.setText(row[0]);
    tvEmail.setText(row[1]);
    tvPhone.setText(row[2]);

    item.setOnClickListener(v -> {
        Toast.makeText(this, getString(R.string.acscro_toast, row[0]), Toast.LENGTH_SHORT).show();
    });

    container.addView(item);
}

1. Inflado Programático con ViewBinding (Kotlin)

val inflater = LayoutInflater.from(this)

contactData.forEach { row ->
    val itemBinding = ItemContactBinding.inflate(inflater, binding.container, false)
    
    itemBinding.tvName.text = row[0]
    itemBinding.tvEmail.text = row[1]
    itemBinding.tvPhone.text = row[2]

    itemBinding.root.setOnClickListener {
        Toast.makeText(this, getString(R.string.acscro_toast, row[0]), Toast.LENGTH_SHORT).show()
    }

    binding.container.addView(itemBinding.root)
}

¿Cuándo usar ScrollView vs RecyclerView?

ScrollView + LinearLayout
  • Listas cortas (< 20 elementos estáticos).
  • Formularios extensos o páginas de ajustes.
  • Prototipado rápido sin necesidad de Adapter ni ViewHolder.
  • Todas las vistas se mantienen vivas en memoria RAM.
RecyclerView (Lab 10)
  • Listas medianas o infinitas (100 a 10,000+ elementos).
  • Reciclaje inteligente: solo ~8 vistas vivas en pantalla.
  • Soporte para animaciones de inserción y DiffUtil.
  • Carga paginada desde base de datos Room o API REST.
