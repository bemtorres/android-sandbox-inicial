Lab 13 · Speech: Text-to-Speech & Speech-to-Text

Aprende a integrar interacción por voz en Android: conversión de texto a voz natural mediante TextToSpeech (TTS) con control de tono, velocidad e idioma, y transcripción de voz a texto mediante RecognizerIntent y el servicio continuo SpeechRecognizer.

🗣️

Text to Speech (TTS)

Sintetiza texto en audio hablado usando el motor nativo de Google TTS o del fabricante.

  • Control de tono (pitch) de 0.5x a 2.0x.
  • Velocidad de habla (speech rate) de 0.5x a 2.0x.
  • Colas de reproducción: QUEUE_FLUSH y QUEUE_ADD.
  • Monitoreo de estado con UtteranceProgressListener.
🎙️

Speech to Text (STT)

Transcribe el audio capturado por el micrófono a cadenas de texto estructuradas.

  • Reconocimiento modal con RecognizerIntent.
  • Permiso de micrófono en tiempo de ejecución (RECORD_AUDIO).
  • Gestión de resultados con ActivityResultLauncher.
  • Soporte multilenguaje con detección automática.

1. Ejemplos de Text to Speech (TTS)

Desde la inicialización básica hasta control acústico de tono, velocidad y exportación de audio.

1.1 Inicialización del Motor TTS, UtteranceProgressListener y Reproducción al Clic

OnInitListener & Speak

Muestra el flujo completo de Text-to-Speech: se define una caja de texto (etTtsInput), un botón (btnSpeak) y una etiqueta de estado (txtTtsStatus). Al iniciar la Activity se crea TextToSpeech con OnInitListener y UtteranceProgressListener; al pulsar el botón, se lee el texto ingresado y el sintetizador lo reproduce en voz alta.

Init, Listeners & Button Click 
// 1. Inicializar el motor TextToSpeech y sus listeners de progreso
textToSpeech = new TextToSpeech(this, new TextToSpeech.OnInitListener() {
    @Override
    public void onInit(int status) {
        if (status == TextToSpeech.SUCCESS) {
            // Configurar idioma por defecto (fallback a Español)
            int result = textToSpeech.setLanguage(Locale.getDefault());
            if (result == TextToSpeech.LANG_MISSING_DATA || result == TextToSpeech.LANG_NOT_SUPPORTED) {
                textToSpeech.setLanguage(new Locale("es", "ES"));
            }

            // Monitorear cuando comienza, finaliza o da error la locución
            textToSpeech.setOnUtteranceProgressListener(new UtteranceProgressListener() {
                @Override
                public void onStart(String utteranceId) {
                    runOnUiThread(() -> txtTtsStatus.setText("Estado: Hablando..."));
                }

                @Override
                public void onDone(String utteranceId) {
                    runOnUiThread(() -> txtTtsStatus.setText("Estado: Listo"));
                }

                @Override
                public void onError(String utteranceId) {
                    runOnUiThread(() -> txtTtsStatus.setText("Estado: Error en locución"));
                }
            });

            isTtsReady = true;
            txtTtsStatus.setText("Estado: Motor TTS Listo");
        } else {
            txtTtsStatus.setText("Estado: Error de inicialización");
        }
    }
});

// 2. Al hacer clic en el botón, lee el texto del input y lo sintetiza en voz alta
btnSpeak.setOnClickListener(v -> {
    if (!isTtsReady || textToSpeech == null) {
        Toast.makeText(this, "El motor TTS aún no está listo", Toast.LENGTH_SHORT).show();

        etTtsInput.setError("Escribe algún texto para hablar");
        return;
    }

    // QUEUE_FLUSH reproduce inmediatamente descartando mensajes previos

});

1.3 Entrada de Texto, Síntesis con speak() y Detención con stop()

QUEUE_FLUSH

Se captura el texto ingresado en etTtsInput, se configuran el tono y la velocidad actuales del motor, y se invoca speak() usando la constante TextToSpeech.QUEUE_FLUSH para interrumpir audios previos. El botón btnStopTts permite cancelar la locución en curso.

Speak & Stop 
// Método para sintetizar el texto del input
private void speakText() {
    if (!isTtsReady || textToSpeech == null) {
        Toast.makeText(this, "El motor TTS aún no está listo", Toast.LENGTH_SHORT).show();
        return;
    }

    String text = etTtsInput.getText() != null ? etTtsInput.getText().toString().trim() : "";
    if (text.isEmpty()) {
        etTtsInput.setError("Escribe algún texto para hablar");
        return;
    }

    float pitch = sliderPitch.getValue();
    float speed = sliderSpeed.getValue();

    textToSpeech.setPitch(pitch);
    textToSpeech.setSpeechRate(speed);

    // QUEUE_FLUSH descarta audios anteriores y habla de inmediato
    textToSpeech.speak(text, TextToSpeech.QUEUE_FLUSH, null, "SANDBOX_TTS_ID");
}

2.1 Gestión de Permiso en Tiempo de Ejecución (RECORD_AUDIO)

RequestPermission

El micrófono es un permiso sensible. Se utiliza ActivityResultContracts.RequestPermission() para solicitar Manifest.permission.RECORD_AUDIO al presionar el botón btnRecognizeIntent si el usuario aún no lo ha otorgado.

Permission Flow 
// Launcher para solicitud de permiso de micrófono
private final ActivityResultLauncher<String> permissionLauncher = registerForActivityResult(
    new ActivityResultContracts.RequestPermission(),
    isGranted -> {
        if (isGranted) {
            launchSpeechRecognizerIntent();
        } else {
            Toast.makeText(this, "Se requiere permiso de micrófono para reconocer voz", Toast.LENGTH_LONG).show();
        }
    }
);

// Click listener del botón para validar permiso previo
btnRecognizeIntent.setOnClickListener(v -> {
    if (ContextCompat.checkSelfPermission(this, Manifest.permission.RECORD_AUDIO)
            == PackageManager.PERMISSION_GRANTED) {
        launchSpeechRecognizerIntent();
    } else {
        permissionLauncher.launch(Manifest.permission.RECORD_AUDIO);
    }
});

2.2 Reconocimiento Modal con RecognizerIntent & Transcripción en txtSttResult

RecognizerIntent

Se dispara el diálogo modal nativo mediante RecognizerIntent.ACTION_RECOGNIZE_SPEECH. La lista de coincidencias devuelta se recupera de RecognizerIntent.EXTRA_RESULTS y la mejor coincidencia se muestra de inmediato en txtSttResult.

RecognizerIntent & Result 
// 1. Registrar ActivityResultLauncher para recibir el texto de voz
private final ActivityResultLauncher<Intent> speechLauncher = registerForActivityResult(
    new ActivityResultContracts.StartActivityForResult(),
    result -> {
        if (result.getResultCode() == Activity.RESULT_OK && result.getData() != null) {
            ArrayList<String> matches = result.getData().getStringArrayListExtra(RecognizerIntent.EXTRA_RESULTS);
            if (matches != null && !matches.isEmpty()) {
                String recognized = matches.get(0); // Mejor coincidencia
                txtSttResult.setText(recognized);
                Toast.makeText(this, "Voz reconocida: " + recognized, Toast.LENGTH_SHORT).show();
            }
        } else {
            txtSttResult.setText("Reconocimiento cancelado o sin audio detectado");
        }
    }
);

// 2. Disparar el Intent de Reconocimiento
private void launchSpeechRecognizerIntent() {
    Intent intent = new Intent(RecognizerIntent.ACTION_RECOGNIZE_SPEECH);
    intent.putExtra(RecognizerIntent.EXTRA_LANGUAGE_MODEL, RecognizerIntent.LANGUAGE_MODEL_FREE_FORM);
    intent.putExtra(RecognizerIntent.EXTRA_LANGUAGE, Locale.getDefault());
    intent.putExtra(RecognizerIntent.EXTRA_PROMPT, "Habla ahora para transcribir...");

    try {
        speechLauncher.launch(intent);
    } catch (Exception e) {
        Toast.makeText(this, "Tu dispositivo no cuenta con servicio de voz", Toast.LENGTH_LONG).show();
    }
}
private val speechLauncher = registerForActivityResult(
    ActivityResultContracts.StartActivityForResult()
) { result ->
    if (result.resultCode == Activity.RESULT_OK && result.data != null) {
        val matches = result.data?.getStringArrayListExtra(RecognizerIntent.EXTRA_RESULTS)
        matches?.firstOrNull()?.let { recognized ->
            binding.txtSttResult.text = recognized
            Toast.makeText(this, "Voz reconocida: $recognized", Toast.LENGTH_SHORT).show()
        }
    } else {
        binding.txtSttResult.text = "Reconocimiento cancelado o sin audio detectado"
    }
}

private fun launchSpeechRecognizerIntent() {
    val intent = Intent(RecognizerIntent.ACTION_RECOGNIZE_SPEECH).apply {
        putExtra(RecognizerIntent.EXTRA_LANGUAGE_MODEL, RecognizerIntent.LANGUAGE_MODEL_FREE_FORM)
        putExtra(RecognizerIntent.EXTRA_LANGUAGE, Locale.getDefault())
        putExtra(RecognizerIntent.EXTRA_PROMPT, "Habla ahora para transcribir...")
    }
    try {
        speechLauncher.launch(intent)
    } catch (e: Exception) {
        Toast.makeText(this, "Tu dispositivo no cuenta con servicio de voz", Toast.LENGTH_LONG).show()
    }
}

2.3 Ciclo de Vida (onDestroy) y Declaración de <queries> en AndroidManifest

Lifecycle & Manifest

Es indispensable liberar la memoria del motor TextToSpeech invocando stop() y shutdown() dentro de onDestroy(). Además, desde Android 11 (API 30), es obligatorio incluir el bloque <queries> en AndroidManifest.xml para permitir que el sistema descubra los servicios de reconocimiento de voz.

Cleanup & Manifest 
@Override
protected void onDestroy() {
    super.onDestroy();
    // Liberar recursos de audio al destruir la Activity
    if (textToSpeech != null) {
        textToSpeech.stop();
        textToSpeech.shutdown();
        Log.d(TAG, "TextToSpeech liberado en onDestroy");
    }
}
override fun onDestroy() {
    super.onDestroy()
    // Liberación del motor en Kotlin
    textToSpeech?.stop()
    textToSpeech?.shutdown()
    Log.d(TAG, "TextToSpeech liberado en onDestroy")
}
