Tutorial técnico
Android Sandbox
de cero a Home → Lab

Proyecto multi-Activity en Java para dominar cada widget sin acoplar módulos. Cada lab es una Activity autónoma con su layout, su validación, su Toast/Dialog y su Log. Navegación explícita con Intent + SharedPreferences fake. Todo el texto externalizado con convención common_ / acXXXX_ y localizado es/en/pt.

Responsive de este tutorial

Mobile-first, drawer con overlay, grid colapsa a 1 col en <1024px, tablas con scroll-x, pros/cons en cards. Tailwind v4 via CDN sin build.

Cómo usar esta web

Navega por páginas (no anclas). Cada página es un HTML independiente. Abre en móvil para probar el drawer. Copia snippets tal cual al proyecto.

Por qué actividades y no Fragments/Navigation

Para aislamiento total: cada lab con su lifecycle onCreate → setContentView → findViewById → listeners. Crashea un lab ≠ rompe Hub. Más verboso pero más didáctico para ver ciclo de vida.

En app real migrarías a Navigation Component + ViewModel + single-activity.
