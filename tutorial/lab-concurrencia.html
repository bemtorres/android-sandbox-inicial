Lab 11 · Concurrencia: Threads & AsyncTask

Aprende a ejecutar código en segundo plano sin congelar la interfaz. Conoce los dos patrones fundamentales: el uso de Worker Threads con Handler/runOnUiThread y el patrón clásico AsyncTask con barra de progreso y cancelación.

La Regla de Oro del Main Thread (UI Thread)

¡Peligro: ANR & Crash!

1. ANR (Application Not Responding): Si bloqueas el Main Thread más de 5 segundos, Android congela la app y muestra el diálogo de forzar cierre.

2. CalledFromWrongThreadException: Intentar modificar una vista desde un hilo secundario sin sincronizar genera un cierre inesperado.

¡La Solución Asíncrona!

1. Worker Thread: Procesa cálculos, temporizadores o I/O en hilos secundarios (new Thread()).

2. Sincronización UI: Regresa al Main Thread con runOnUiThread(), Handler(Looper.getMainLooper()) o AsyncTask.

1 Ejemplo Exclusivo: Worker Thread + runOnUiThread

Creación de un hilo nativo en Java/Kotlin con actualización progresiva de la interfaz.

java.lang.Thread

Un Thread permite derivar una secuencia de instrucciones para que corran en paralelo al hilo principal. Para interactuar con la pantalla durante el progreso, se despacha un Runnable a la cola del hilo principal mediante activity.runOnUiThread() o Handler.post().

Worker Thread 
// Ejemplo Exclusivo: Worker Thread en Java 11
private void ejecutarWorkerThread() {
    btnStartThread.setEnabled(false);
    progressThread.setProgress(0);
    txtThreadStatus.setText("Hilo secundario en ejecución...");

    // 1. Crear e iniciar el hilo en segundo plano
    new Thread(new Runnable() {
        @Override
        public void run() {
            // Este código corre en un Worker Thread (NO bloquea la UI)
            for (int i = 1; i <= 100; i += 10) {
                try {
                    Thread.sleep(250); // Carga pesada simulada
                } catch (InterruptedException e) {
                    return;
                }
                
                final int progreso = i;
                // 2. Regresar al UI Thread para actualizar vistas
                runOnUiThread(new Runnable() {
                    @Override
                    public void run() {
                        progressThread.setProgress(progreso);
                        txtThreadStatus.setText("Progreso: " + progreso + "%");
                    }
                });
            }

            // 3. Notificación de fin de tarea en el UI Thread
            runOnUiThread(new Runnable() {
                @Override
                public void run() {
                    progressThread.setProgress(100);
                    txtThreadStatus.setText("¡Worker Thread finalizado con éxito!");
                    btnStartThread.setEnabled(true);
                    Toast.makeText(ConcurrencyActivity.this, "Hilo completado", Toast.LENGTH_SHORT).show();
                }
            });
        }
    }).start(); // ¡start() lanza el nuevo hilo!
}
// Ejemplo Exclusivo: Worker Thread en Kotlin
private fun ejecutarWorkerThread() {
    binding.btnStartThread.isEnabled = false
    binding.progressThread.progress = 0
    binding.txtThreadStatus.text = "Hilo secundario en ejecución..."

    // Función nativa thread {} de Kotlin
    kotlin.concurrent.thread {
        for (i in 1..100 step 10) {
            Thread.sleep(250) // Carga pesada en Worker Thread
            
            // Regreso al UI Thread
            runOnUiThread {
                binding.progressThread.progress = i
                binding.txtThreadStatus.text = "Progreso: $i%"
            }
        }

        runOnUiThread {
            binding.progressThread.progress = 100
            binding.txtThreadStatus.text = "¡Worker Thread finalizado con éxito!"
            binding.btnStartThread.isEnabled = true
            Toast.makeText(this@ConcurrencyActivity, "Hilo completado", Toast.LENGTH_SHORT).show()
        }
    }
}

2 Ejemplo Exclusivo: Patrón AsyncTask Completo

Manejo estructurado del ciclo de vida asíncrono con parámetros, progreso y cancelación.

android.os.AsyncTask

AsyncTask<Params, Progress, Result> encapsula la comunicación entre el hilo de fondo y la UI en 4 etapas bien definidas:

1. onPreExecute() UI Thread

Prepara la UI antes de empezar (activa spinners, resetea barras).

2. doInBackground() Background

Ejecuta la tarea pesada. Emite avances con publishProgress().

3. onProgressUpdate() UI Thread

Recibe el progreso emitido y actualiza la vista en tiempo real.

4. onPostExecute() UI Thread

Recibe el resultado final retornado por doInBackground y restaura botones.

AsyncTask Lifecycle 
// Ejemplo Exclusivo: Clase AsyncTask Completa en Java 11
private class HeavyCalculationTask extends AsyncTask<Integer, Integer, String> {

    // 1. Antes de iniciar (En hilo principal)
    @Override
    protected void onPreExecute() {
        super.onPreExecute();
        btnStartAsync.setEnabled(false);
        btnCancelAsync.setEnabled(true);
        progressAsync.setProgress(0);
        txtAsyncStatus.setText("Iniciando tarea asíncrona...");
    }

    // 2. En segundo plano (Worker Thread)
    @Override
    protected String doInBackground(Integer... params) {
        int limite = (params.length > 0) ? params[0] : 100;
        
        for (int i = 1; i <= limite; i += 10) {
            // Verificar si el usuario canceló la tarea
            if (isCancelled()) {
                return "Tarea cancelada por el usuario";
            }
            try {
                Thread.sleep(200); // Simular cálculo pesado
            } catch (InterruptedException e) {
                return "Interrumpido";
            }
            
            // Envía el valor actual a onProgressUpdate() en el UI Thread
            publishProgress(i);
        }
        return "¡Descarga de datos completada con éxito!";
    }

    // 3. Actualización de progreso (En hilo principal)
    @Override
    protected void onProgressUpdate(Integer... values) {
        super.onProgressUpdate(values);
        int porcentaje = values[0];
        progressAsync.setProgress(porcentaje);
        txtAsyncStatus.setText(String.format("AsyncTask: %d%%", porcentaje));
    }

    // 4. Conclusión exitosa (En hilo principal)
    @Override
    protected void onPostExecute(String resultado) {
        super.onPostExecute(resultado);
        txtAsyncStatus.setText(resultado);
        progressAsync.setProgress(100);
        btnStartAsync.setEnabled(true);
        btnCancelAsync.setEnabled(false);
        Toast.makeText(ConcurrencyActivity.this, resultado, Toast.LENGTH_SHORT).show();
    }

    // 5. Cancelación (En hilo principal)
    @Override
    protected void onCancelled(String resultado) {
        super.onCancelled(resultado);
        txtAsyncStatus.setText(resultado != null ? resultado : "Cancelado");
        btnStartAsync.setEnabled(true);
        btnCancelAsync.setEnabled(false);
    }
}

// Ejemplo Exclusivo: Equivalente en Kotlin con Coroutines y Flow
private fun ejecutarTareaModerna() {
    lifecycleScope.launch {
        binding.btnStartAsync.isEnabled = false
        binding.btnCancelAsync.isEnabled = true
        binding.progressAsync.progress = 0
        binding.txtAsyncStatus.text = "Iniciando corrutina..."

        // Ejecutar en hilo de entrada/salida (IO)
        val resultado = withContext(Dispatchers.IO) {
            for (i in 1..100 step 10) {
                delay(200)
                // Reportar progreso al hilo principal (Main)
                withContext(Dispatchers.Main) {
                    binding.progressAsync.progress = i
                    binding.txtAsyncStatus.text = "Corrutina: $i%"
                }
            }
            "¡Descarga completada con Coroutines!"
        }

        binding.txtAsyncStatus.text = resultado
        binding.progressAsync.progress = 100
        binding.btnStartAsync.isEnabled = true
        binding.btnCancelAsync.isEnabled = false
    }
}
