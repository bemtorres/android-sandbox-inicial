Lab 6 — WebView

Renderiza web dentro de la app. Muestra ciclo onPageStarted → onPageFinished, WebSettings, back handling y permiso INTERNET.

WebView webView = findViewById(R.id.webView);
ProgressBar progress = findViewById(R.id.wvProgress);
webView.getSettings().setJavaScriptEnabled(true);
webView.getSettings().setDomStorageEnabled(true);
webView.setWebViewClient(new WebViewClient(){
  @Override void onPageStarted(WebView v, String url, Bitmap favicon){
    progress.setVisibility(View.VISIBLE);
    Log.d(TAG, "onPageStarted: "+url);
  }
  @Override void onPageFinished(WebView v, String url){
    progress.setVisibility(View.GONE);
    Log.i(TAG, "onPageFinished: "+url);
  }
});
findViewById(R.id.btnLoad).setOnClickListener(v->{
  String url="https://developer.android.com";
  webView.loadUrl(url);
  Toast.makeText(this, getString(R.string.acwebv_toast_loading, url), SHORT).show();
});
findViewById(R.id.btnBack).setOnClickListener(v->{
  if(webView.canGoBack()) webView.goBack();
  else Toast.makeText(this, getString(R.string.common_msg_no_history), SHORT).show();
});
@Override void onBackPressed(){
  if(webView.canGoBack()) webView.goBack(); else super.onBackPressed();
}

Layout técnico

<LinearLayout orientation="vertical" height="match_parent">
  <MaterialCardView> // header acwebv_info_desc + 2 buttons + ProgressBar</MaterialCardView>
  <WebView android:layout_weight="1" height="0dp"/> // ocupa resto
</LinearLayout>

weight 1 hace que WebView llene hueco. Card superior fixed 120dp.

Seguridad / permisos

Sin <uses-permission INTERNET> → net::ERR_CACHE_MISS. setJavaScriptEnabled(true) necesario para developer.android.com. Si añades setAllowFileAccess(false) endureces. En prod añade shouldOverrideUrlLoading para controlar navegación.

Responsive específico WebView

WebView escala contenido con viewport. En móvil 360dp renderiza responsive de developer.android.com. Botones Cargar/Atrás en LinearLayout horizontal con weight 1 y wrap_content → en móvil pequeño Cargar ocupa 70% y Atrás 30%. ProgressBar 4dp fino.
