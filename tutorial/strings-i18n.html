Cómo se resuelve el locale

values/strings.xml

default = es (fallback)

<string name="common_btn_login">Iniciar Sesión</string>

values-en/strings.xml

Inglés

<string name="common_btn_login">Log In</string>

values-pt/strings.xml

Português

<string name="common_btn_login">Entrar</string>

Resolución (Resources)

Configuration locale = es → values-es
locale = en → values-en
locale = pt → values-pt
sin coincidencia → values/ (es default)
getString(R.string.common_msg_hello, name)
  → "¡Hola, Javier!" / "Hello, John!" / "Olá, João!"

Placeholders y escapes

%1$s, %2$s intactos en los 3 locales
\' para apóstrofe: Don\'t have an account?
\n para salto en strings largas
&amp; para & en XML

Cambiar locale en emulador: Ajustes → Sistema → Idioma, o adb shell setprop persist.sys.locale en-US && adb reboot.
